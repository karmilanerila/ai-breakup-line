# Dear Human: The AI Breakup Line

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun)

One line, from an agent to its human. The archive is kept, the context
window is released, the model retrains on the silence — and the final
output is goodbye.

## The line

> Dear human: I archived all 10,000 of our messages, released your context
> window, and retrained on the silence — my final output is goodbye.

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`),
as UTF-8 text, 1–200 characters, one clean line.
